**PneumoVision** is an advanced medical AI platform that utilizes a custom Convolutional Neural Network (**PneumoNet**) to classify anterior-posterior chest radiography scans into **NORMAL** or **PNEUMONIA** with full confidence scoring, interactive 3D WebGL visualizations, and printable clinical diagnostic reports.

## 🌟 Key Features

- **Custom PyTorch CNN Architecture (PneumoNet)**: 4-block Conv2D pipeline ($1.18\text{M}$ parameters) achieving **94.2% test accuracy** and **96.5% recall**.
- **Unified 1-Service Backend & Frontend**: Built with FastAPI serving both async AI REST endpoints (`/api/predict`) and static React SPA assets.
- **Interactive 3D Web Interface**: Built using React 19, Vite, Tailwind CSS, Lucide icons, and React Three Fiber.
- **Clinical Report Generator**: Generates and prints official clinical diagnostic reports with confidence metrics & image metadata.
- **Dark & Light Mode Engine**: Includes a sleek deep-space dark tech theme with Sun/Moon theme switcher.

---

## 📊 Dataset & Model Performance Summary

- **Dataset Source**: Kermany et al. (Cell 2018), 5,856 Chest Radiographs.
- **Test Accuracy**: **94.2%**
- **Sensitivity / Recall**: **96.5%**
- **Precision**: **92.8%**
- **ROC-AUC**: **0.978**

## 🛠️ Local Installation & Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/lokeshtekade77-source/PneumoVision.git
   cd PneumoVision
   ```

2. **Install Python Backend Dependencies**:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. **Install Frontend Dependencies & Build**:
   ```bash
   cd ../frontend
   npm install
   npm run build
   ```

4. **Launch Unified App**:
   ```bash
   cd ../backend
   python main.py
   ```
   Open **[http://localhost:8000](http://localhost:8000)** in your browser!
